# MergeGuard AI

GitHub PR의 코드 변경 사항과 협업 충돌 위험을 분석하여 merge 안정성을 높이는 AI 기반 PR 리뷰 시스템입니다.

## Tech Stack

- Backend: FastAPI
- Frontend: Next.js
- External API: GitHub REST API
- LLM: Gemini API
